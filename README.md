# 🌦️ Real-Time Weather API Dashboard

Developed a real-time weather analytics dashboard using **Power BI** integrated with the **OpenWeatherMap API** to visualize live weather conditions across global cities. The dashboard delivers interactive insights through dynamic KPIs and automated real-time updates.

---

## 🚀 Features

- 🌍 Live Weather Monitoring across multiple global cities
- 🌡️ Real-time KPIs for:
  - Temperature
  - Humidity
  - Atmospheric Pressure
  - Wind Speed
  - Weather Conditions
- 🧩 JSON data parsing and transformation using Power Query
- 🗺️ Interactive geographical map visualizations for city-wise comparison
- 📊 Clean, responsive, and user-friendly dashboard design for quick insights
- 🔄 Automated scheduled refresh for continuous live tracking

---
