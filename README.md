# -Real-Time-Weather-API-Dashboard
Developed a real-time weather analytics dashboard using Power BI integrated with the Weather API to visualize live weather conditions across global cities. The dashboard delivers interactive insights through dynamic KPIs and automated real-time updates.

🚀 Features
🌍 Live Weather Monitoring across multiple global cities
🌡️ Real-time KPIs for:
Temperature
Humidity
Atmospheric Pressure
Wind Speed

Weather Conditions
🧩 JSON data parsing and transformation using Power Query
🗺️ Interactive geographical map visualizations for city-wise comparison
📊 Clean, responsive, and user-friendly dashboard design for quick insights
🔄 Automated scheduled refresh for continuous live tracking

🛠️ Tech Stack
📈 Power BI
🌐 OpenWeatherMap API
🔄 Power Query
📄 JSON
📍 RestApis

📷 Dashboard Highlights
✨ Real-time analytics
✨ Dynamic KPI cards
✨ Global city comparison
✨ Interactive visuals and filters

💡 Key Learnings
API integration in Power BI
Handling and transforming nested JSON data
Designing intuitive analytical dashboards
